# STAR BROADCASTING CO.

성인용 데스크톱 방송국 경영 시뮬레이션 게임.

플레이어는 방송국 CEO가 되어 크리에이터를 영입·관리하고, 주간 스케줄을 짜며, 장비를 강화하고, 매월 정산을 통해 방송국을 성장시킵니다.

---

## 게임 컨셉

- 방송국 CEO로서 크리에이터(방송인)를 영입하고 관리한다.
- 각 크리에이터는 능력치를 가진다.
  - 인기, 스킬, 수위 레벨(1~4), 충성도, 체력, 피로도, 호감도
- 크리에이터 등급: `S` / `A` / `B` / `C`
  - 등급에 따라 최대 능력치와 수익 배율이 달라진다.
- 주간 스케줄(월~일, 하루 1명)에 크리에이터를 배치한다.
  - 배치하지 않은 요일은 **개쉐이**(휴식)로 표시된다.
- 방송 수익은 크리에이터 능력치와 장비 보너스에 따라 산출된다.
- 장비 강화: 카메라, 조명, 마이크, PC, 인터넷, 배경/세트
- 크리에이터 케어: 선물, 휴가, 교육, 데이트 등
- 스카우트 / 방출로 로스터를 관리한다.
- 매월 정산: `수익 - 운영비 - 급여 - 세금`
- 긍정/부정 랜덤 이벤트가 발생한다.
- 성과에 따라 다양한 엔딩이 있다.

## UI 구조

```
┌──────────────────────────────────────────────────────┐
│  상단 헤더: 방송국명 · 자산 · 주차 · 배속 조절      │
├──────────────────────────────────────────────────────┤
│                                                      │
│  중앙: 각 페이지의 주요 콘텐츠                       │
│                                                      │
├──────────────────────────────────────────────────────┤
│  하단 네비게이션                                     │
│  DASHBOARD · CREATOR · SCHEDULE · EQUIPMENT · SETTINGS │
└──────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| 상단 헤더 | 방송국명, 자산, 주차, 배속 조절 (자산은 상시 고정 표시) |
| 중앙 콘텐츠 | 선택한 탭의 메인 화면 |
| 하단 네비게이션 | 대시보드 / 크리에이터 / 스케줄 / 장비 / 설정 |

### 페이지

- **DASHBOARD** — 자산·오늘 수익·크리에이터 수, 오늘의 방송, 최근 이벤트
- **CREATOR** — 검색·등급 필터·스카우트, 크리에이터 카드 그리드
- **SCHEDULE** — 주간 배치 그리드, 배속/자동 진행, 배치용 카드 트레이
- **EQUIPMENT** — 장비 2열 그리드, 강화
- **SETTINGS** — 설정 (준비 중)

## 실행 방법

### 개발 모드 (Vite + Electron)

```bash
npm run dev
```

또는 `start-dev.bat` 더블클릭.

- Vite: `http://localhost:5173`
- Electron이 개발 서버를 로드한다.
- UI 변경은 HMR로 반영된다. (`F5` / `Ctrl+R`로 강제 새로고침 가능)

### 프로덕션 빌드 후 실행

```bash
npm run build
npm start
```

또는 `start.bat` 더블클릭.
