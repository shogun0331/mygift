# STAR BROADCASTING CO.

성인용 데스크톱 **방송국 경영 시뮬레이션** 게임.

플레이어는 방송국 CEO가 되어 크리에이터를 영입·관리하고, 주간 스케줄을 짜며, 장비를 강화하고, 방송을 운영해 수익을 키워 나간다.

**저장소:** https://github.com/shogun0331/mygift  
**패키지명:** `broadcast-game`

## 게임 컨셉 (목표 설계)

- 방송국 CEO로서 크리에이터(방송인)를 영입하고 관리한다.
- 크리에이터 능력치: 인기, 스킬, 수위 레벨(1~4), 충성도, 체력, 피로도, 호감도
- 등급: `S` / `A` / `B` / `C` — 최대 능력치·수익 배율 차이
- 주간 스케줄(월~일, 하루 1명) 배치 — 미배치는 **개쉐이**(휴식)
- 방송 수익 = 크리에이터 능력치 + 장비 보너스
- 장비 강화: 카메라, 조명, 마이크, PC, 인터넷, 배경/세트
- 케어: 선물, 휴가, 교육, 데이트 등
- 스카우트 / 방출
- 매월 정산: `수익 - 운영비 - 급여 - 세금`
- 긍정/부정 랜덤 이벤트
- 성과에 따른 다양한 엔딩

## 실행 방법

### 사전 요구

- Node.js (npm 포함)

### 설치

```bash
npm install
```

### 개발 모드 (Vite + Electron)

```bash
npm run dev
```

또는 `start-dev.bat` 더블클릭.

- Vite: `http://localhost:5173`
- Electron이 개발 서버를 로드
- UI는 HMR로 반영 (`F5` / `Ctrl+R` 강제 새로고침 가능)
- 메인 메뉴에 **[EDIT]** 버튼 표시됨

### 프로덕션 빌드 후 실행

```bash
npm run build
npm start
```

또는 `start.bat` 더블클릭.

- React를 `dist/`에 빌드 후 Electron이 로드
- **EDIT 버튼은 빌드본에서 표시되지 않음**
