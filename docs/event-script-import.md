# 이벤트 관리 — 스크립트 가져오기

에디터 **이벤트 관리**에서 대본 텍스트를 붙여 넣으면, 한 줄씩 파싱해 **그래픽 노드**와 **텍스트 노드**를 자동으로 만듭니다.

이 문서는 현재 에디터가 실제로 읽는 문법입니다. 형식이 다르면 대사가 지문으로 들어가거나, 그래픽이 비어 있는 노드가 생깁니다.

---

## 들어가기

1. 메인 메뉴에서 **EDIT** → **이벤트 관리**
2. 왼쪽 목록에서 이벤트를 **먼저 선택**합니다. (선택이 없으면 버튼이 없습니다.)
3. 오른쪽 **노드 시퀀스** 탭에서 **스크립트 가져오기**를 누릅니다.
4. 대본을 붙여 넣거나 **.txt 파일을 끌어다 놓고**, 가져오기 방식을 고른 뒤 **스크립트 반영하기**를 누릅니다.

txt는 모달 안이나 노드 시퀀스 패널에 드롭해도 됩니다. `txt 열기`로 고를 수도 있습니다. UTF-8(BOM 포함)·UTF-16을 읽습니다.

### 가져오기 방식

| 방식 | 동작 |
|------|------|
| **기존 노드 뒤에 추가** | 지금 있는 노드를 그대로 두고, 맨 뒤에 붙입니다. |
| **기존 노드 전체 덮어쓰기** | 기존 노드를 전부 지우고, 붙여 넣은 대본만 남깁니다. |

빈 줄은 무시됩니다. 줄 앞뒤 공백은 잘립니다.

---

## 한 줄 = 노드 하나

줄마다 아래 순서로 판별합니다.

1. `그래픽:` 으로 시작하면 → **그래픽 노드**
2. `페이드:` 로 시작하면 → **페이드 노드**
3. `이름: 대사` 형태면 → **텍스트 노드** (화자에 따라 캐릭터 / 플레이어 / 지문)
4. 콜론(`:` 또는 `：`)이 없으면 → **텍스트 노드 + 지문**

반각 콜론 `:` 과 전각 콜론 `：` 모두 됩니다.

텍스트 노드는 에디터에서 형태가 하나이고, **화자 타입**만 다릅니다.

| 화자 타입 | 에디터 버튼 | 스크립트에서 쓰는 법 |
|-----------|-------------|----------------------|
| 등록 캐릭터 | 등록 캐릭터 | `세아: 대사` (캐릭터 관리의 이름과 동일) |
| 플레이어 | 플레이어 | `플레이어: 대사` 또는 `player: 대사` |
| 지문 | 지문 | `지문: 설명` 또는 콜론 없는 한 줄 |

---

## 1. 그래픽 노드

```
그래픽: 설명 문구
```

- `그래픽:` 뒤 텍스트는 장면 설명입니다.
- 기본 노출 시간은 **2초**입니다. 가져온 뒤 노드에서 바꿀 수 있습니다.
- 설명이 **이미 연결된 미디어 파일명**과 겹치면 자동으로 붙입니다. (대소문자 무시, 부분 문자열)

파일명이 설명과 비슷하지 않으면 미디어는 비어 있습니다. 그 경우 그래픽 노드에서 **배경 미디어**를 직접 고르거나, 파일을 드롭하면 됩니다.

**잘 되는 예**

```
그래픽: living_room.png
그래픽: 거실
```

이벤트에 `living_room.png` 가 있으면 둘 다 매칭될 수 있습니다. (`거실`은 파일명에 `거실`이 들어 있을 때만)

**안 붙는 예**

```
그래픽: #1 — 거실 입구 (풀샷)
```

파일명이 `ev01_living.jpg` 처럼 전혀 다르면 노드는 생기지만 미디어는 비어 있습니다. 정상입니다. 가져온 뒤 미디어만 연결하세요.

---

## 2. 텍스트 노드 — 캐릭터 / 플레이어 대사

```
화자이름: 대사 내용
```

| 화자 적는 법 | 결과 |
|--------------|------|
| `플레이어` 또는 `player` | 화자 타입 **플레이어** |
| `지문` / `나레이션` / `narrator` | 화자 타입 **지문** (아래 3절) |
| **캐릭터 관리에 등록된 이름과 완전히 같게** | 그 캐릭터 ID로 연결 |
| 등록되지 않은 이름 | 그 문자열을 화자 ID/이름으로 그대로 사용 |

이름은 **정확히** 같아야 합니다. `세아`로 등록했는데 `세아양`으로 쓰면 다른 화자로 들어갑니다.

**예**

```
이모: 너, 잠 안 와?
플레이어: 이모, 많이 드셨어요?
세아: 오늘 방송 괜찮았어?
```

가져온 뒤 카드에서 화자 타입을 **등록 캐릭터 / 플레이어 / 지문**으로 바꿔도 됩니다.

---

## 3. 텍스트 노드 — 지문

지문은 별도 노드 종류가 아닙니다. **텍스트 노드**이고, 화자 타입이 **지문(narrator)** 입니다. 시뮬레이터에서는 이름표 없이 문장만 나갑니다.

### 쓰는 법 (둘 다 됩니다)

**1) `지문:` 으로 시작 (권장)**

```
지문: 거실 불이 꺼져 있다.
지문: 잠시 침묵이 흐른다.
나레이션: 문이 천천히 열린다.
```

`지문` / `나레이션` / `narrator` 뒤에 콜론을 붙이면 화자 타입이 지문으로 들어갑니다. 콜론 뒤가 화면에 나올 문장입니다.

**2) 콜론 없는 한 줄**

```
거실 불이 꺼져 있다.
잠시 침묵이 흐른다.
```

콜론이 전혀 없으면 그 줄 전체가 지문입니다.

### 하면 안 되는 것

| 잘못된 줄 | 실제로 되는 일 |
|-----------|----------------|
| `시간: 밤` | 화자가 `시간`, 대사가 `밤`인 **캐릭터 대사**가 됨 |
| `(지문) 불이 꺼진다.` | 콜론이 없어서 통째로 지문이 되긴 하지만, `(지문)`까지 화면에 나옴 |
| `지문 불이 꺼진다.` | 콜론이 없으면 문장 전체가 지문. `지문:` 접두어는 인식되지 않음 |

지문 문장 **안에** 콜론이 있으면, 접두어 없이 쓰면 첫 콜론에서 대사가 쪼개집니다.

```
시계는 아직 3:00 을 가리킨다.     ← 화자 `시계는 아직 3` + 대사 `00 을 가리킨다` 가 됨
지문: 시계는 아직 3:00 을 가리킨다.  ← 문장 전체가 지문으로 들어감
```

## 작성 예시

아래를 그대로 붙여 넣어도 됩니다.

```
그래픽: 거실 입구
지문: 거실에 불이 켜져 있다.

이모: 너, 잠 안 와?
플레이어: 이모, 많이 드셨어요?
이모: 괜찮아. 앉아.

그래픽: 테이블
세아: 내일 스케줄은 내가 볼게.
플레이어: 고마워.
지문: 잠깐 웃음이 스친다.
```

가져오면 대략 이런 순서가 됩니다.

1. 그래픽 (거실 입구)
2. 지문
3. 이모 대사
4. 플레이어 대사
5. 이모 대사
6. 그래픽 (테이블)
7. 세아 대사
8. 플레이어 대사
9. 지문

---

## 가져온 뒤 할 일

1. **그래픽 노드** — 미디어가 비어 있으면 파일을 연결합니다.
2. **텍스트 노드** — 화자 타입이 맞는지 봅니다. 대사는 등록 캐릭터/플레이어, 설명 문장은 **지문**. 이름이 달랐으면 드롭다운에서 고칩니다.
3. 카드 **↕** 로 순서를 바꿉니다.
4. **시뮬레이터 (디버그 / 인게임)** 로 재생해 봅니다.
5. 에디터 상단 **이벤트 저장**으로 저장합니다.

---

## 자주 생기는 실수

| 증상 | 원인 | 대처 |
|------|------|------|
| 창이 안 보이거나 버튼이 없음 | 이벤트를 선택하지 않음 | 왼쪽 목록에서 이벤트를 먼저 클릭 |
| 한 줄이 통째로 지문이 됨 | 콜론이 없음 | 대사는 `이름: 대사`, 지문은 `지문: 문장` |
| 화자 이름이 `지문`으로 등록됨 | `지문` 뒤에 콜론이 없음 | `지문: 문장` 으로 쓰기 |
| `시간: 밤` 이 대사가 됨 | 지문에 접두어 없이 콜론을 씀 | `지문: 시간은 밤이다.` |
| 그래픽만 생기고 화면이 비어 있음 | 설명과 파일명이 안 맞음 | 노드에서 미디어를 직접 선택 |
| 화자가 등록 캐릭터가 아님 | 이름이 한 글자라도 다름 | 캐릭터 관리의 이름과 동일하게, 또는 가져온 뒤 드롭다운에서 선택 |
| 기존 스토리가 사라짐 | **덮어쓰기**를 선택함 | 이어 붙이려면 **기존 노드 뒤에 추가** |
| `그래픽 : 장면` 처럼 이상하게 나뉨 | `그래픽` 뒤에 콜론이 없음 | 반드시 `그래픽:` 으로 시작 |

---

## 문법 요약

```
그래픽: <장면 설명 또는 파일명>
페이드: 인 | 아웃
<화자>: <대사>
플레이어: <플레이어 대사>
지문: <설명 문장>
<콜론 없는 문장>          ← 지문 (접두어 없이도 됨)
```

한 줄에 노드 하나만 넣습니다. 한 줄에 대사 여러 개를 붙이지 마세요.
