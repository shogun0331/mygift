# 토큰

- 요청한 파일만 읽는다. 검색 전에 경로를 디렉터리나 글로브로 좁힌다.
- `node_modules`, `out`, `dist`, `release`는 검색하지 않는다.
- 파일은 역할 단위로 나눈다. 설계 설명은 코드 주석 대신 규칙과 이 스킬에 둔다.
- 기능이 끝나면 새 채팅을 연다.
- 설계 변경은 Plan, 구현 한 덩어리는 Agent로 나눈다.
- 상시 규칙은 경계만 남긴다. 절차 본문은 이 스킬에만 둔다.
