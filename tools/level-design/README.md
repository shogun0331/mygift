# 방송국 밸런스 시뮬레이션 작업 문서

> 이 문서는 broadcast-game의 레벨디자인(프로그레션 밸런스) 시뮬레이션 작업 전 과정을 기록합니다.
> 산출물: `balance-sim.cjs`(시뮬레이터) · `report.md`(자동 리포트) · `design-targets.md`(목표 테이블)

---

## 1. 목적 & 설계 기준

게임의 성장 곡선(리그 등반 · 방송국 티어 승급)을 **수치 시뮬레이션으로 검증·튜닝**하기 위한 작업입니다.

| 기준 | 값 |
| --- | --- |
| 클리어 목표 | **1위(일등기업)까지 실질 플레이타임 2시간 이상** |
| 시간 환산 | 게임 내 1년 ≈ 15분 (빠른 플레이, 플레이어 제공) |
| 승급 제약 | **연 1회(1월 심사)** → 일등기업까지 **최소 5년(60개월)** |
| 곡선 철학 | **"매번 간신히 승급" 금지** — 여유 있는 티어 + **한 티어는 심사를 놓쳐 2년** 걸리는 자연 변동 |

## 2. 시뮬레이터 (`tools/level-design/balance-sim.cjs`)

실제 게임 로직(`src/game/*`, `public/chapter_assets/*`)을 재현한 **월 단위 통합 헤드리스 시뮬레이터**입니다.

### 재현 범위
- **시청자**: 성장 18%/월(잠재력 방향) · 유기성장 10%/월(잠재력 도달 후) · 휴식 감소 4%/월
  잠재력 = `150 + Σ(소통 × 가중치 × 등급배율) + 구독 × 0.2`
- **순위**: 티어 게이트 (black 151~300 · tiny 101~150 · sme 51~100 · mid 21~50 · large 11~20 · top 1)
- **티어 승급**: 연 1회(1월 심사), 1단계씩, 요구 시청자 + 크리에이터 등급 조건
- **경제**: 방송 수익 · 월급 · 슬롯 운영비 · 트레이닝비(유료 공식) · 승급 심사비 · 3월 누진 과세
- **스카우트**: 전부 C등급, 오프닝 1명 무료 보장, 이후 2~4턴·70% 성공
- **훈련/심사**: 무료 아님, C→B $52K(80%) / B→A $210K(60%) / A→S $780K(40%)
- **스탭**: 첫 3개월, 이후 3개월 쿨다운 50%

### 실행 방법
```bash
# 기본 (300회 × 96개월 × 시나리오 3종)
node tools/level-design/balance-sim.cjs

# 실행 수/기간 변경
SIM_RUNS=500 SIM_MONTHS=120 node tools/level-design/balance-sim.cjs

# 튜닝 파라미터 스윕 (env 주입)
SIM_VPCP=160 SIM_ORG=0.10 SIM_MID=20000 SIM_LARGE=80000 SIM_TOP=250000 \
SIM_MID_G=B SIM_MID_C=2 SIM_LG_G=A SIM_LG_C=2 SIM_TP_G=S SIM_TP_C=1 \
node tools/level-design/balance-sim.cjs
```

## 3. 작업 과정 (요약)

### 3-1. 1단계 — 현재 곡선 분석 (기존 밸런스 진단)
- **결과**: 티어 승급이 사실상 불가능에 가까웠음
  - sme(5천) 26개월, **mid(10만) 8년 내 0% 도달**, 1위 클리어 약 30년(게임 내) 예상
- **원인 분석**
  - 로스터 잠재력 상한(소통×50×등급배율)이 낮아 mid/large 요구에 미달
  - 유기성장 2%/월로는 격차를 못 메움
  - 스카우트 주기(3~6턴·50%)가 느려 로스터 구축이 병목
- **부가 발견**: 마일스톤 UI(50위=10K·B2)와 실제 티어 게이트(mid=10만·A2)의 **10배 불일치**

### 3-2. 2단계 — 1차 튜닝 (초기 적용)
- 소통가중치 50→**300**, 유기성장 2%→**12%**, 티어 요구 대폭 하향
- 연 1회 승급 적용, 트레이닝 유료화, 승급 목표 UI 정합
- **결과(시뮬)**: 목표 회차에 맞는 곡선이 나왔지만 → **플레이어 피드백으로 실패 판정**
  - "3개월 만에 5천명" — 초반 티어가 무의미
  - "매번 간신히/2년씩 걸림" — 자연 변동 부재

### 3-3. 3단계 — 재교정 (자연 변동 곡선, 현재)
- **소통가중치 300→160** — 초반 과잉 성장 제거 (1명 잠재력 ≈ 3~5천명 수준)
- **스카우트 3~6턴·50% → 2~4턴·70%** — 로스터 성장을 곡선에 맞춰 자연 변동 확보
- **요구 시청자를 잠재력 곡선에 맞춰 독립 재결정**: large 80K · top 250K
- 시뮬레이션 반복 스윕으로 "여유 있는 티어 + 한 번은 2년" 리듬 확정

## 6. 남은 과제 / 향후

1. **도박 미니게임(자산 성장) 미구현** — 8년차 자산 중앙값 $81M로 풍부하므로 "선택적 재미 요소"로 설계 권장.
   로스터(영입비·심사비 지원)와 시너지 나는 보상 형태가 자연스러움.
2. **플레이어 실플레이 피드백** — 시뮬레이션은 "보통 플레이"와 실제 체감이 다를 수 있음.
   직접 플레이 후 "large가 빡빡/느슨" 등의 피드백 → 해당 파라미터만 미세조정.
3. ~~성장 상수의 JSON화(선택)~~ → **완료**: 시청자 성장 밸런스는 `station_grade_config.json`의
   `balance` 섹션에서 관리 (로드 시 자동 적용). 에디터 UI에 balance 입력란을 추가하는 것은 추후 선택 과제.
